Application Pages:
The app is divided into several main screens that guide the user through their fitness journey. It starts with Login and Registration pages, where users can securely create an account or sign in using JWT-based authentication. After logging in, users reach the Home Dashboard, which serves as the main navigation hub. The Exercises page displays a list of available exercises with details that help users understand each movement. The Workouts page allows users to create, edit, and delete workout plans, each containing multiple exercises. Inside a workout, the Workout Details page shows the full routine structure. The Progress page visualizes workout history and performance using charts and statistics. Finally, the Profile page lets users update their personal information and upload a profile picture.

Key Features:
-Secure user authentication (register/login) with encrypted passwords
-JWT-based authorization for protected API access
-Exercise browsing and management
-Custom workout creation with multiple exercises per workout
-Workout progress logging and history tracking
-Visual statistics and performance charts
-Persistent login using local token storage
-Profile management with image upload support
-RESTful API communication between Flutter app and backend
-Local SQLite database for structured data storage

Project purpose:
The purpose of this project is to demonstrate the development of a complete full-stack mobile application that combines frontend, backend, and database technologies into one integrated system. It showcases how Flutter can be used to build a responsive mobile interface while a Node.js and Express backend handles authentication, business logic, and data storage. The project also highlights important software engineering concepts such as state management, RESTful API integration, secure authentication, and data visualization. Beyond its technical goals, the app provides a practical solution for users to plan workouts, track their fitness progress, and stay motivated through measurable results.
